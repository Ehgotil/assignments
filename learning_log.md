# Learning Log

## Week 1
In this week I learned the fundamentals of what an Arduino is (the one we are using is an 8-bit AVR microcontroller with 32KB Memory) and what programming language we will use in the ArduinoIDE to interface with it (C++).
Other components were also introduced such as breadboards and resistors. I used this newfound knowledge to make an LED light up on a breadboard connected to an Arduino.
